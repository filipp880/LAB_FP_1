# ЛР1: переносное резервное хранилище

Консольная программа сохраняет выбранные файлы в ZIP-контейнер, находит изменения,
ведёт историю и восстанавливает выбранную версию. Требования: [Task1.txt](Task1.txt)
и [Task3.md](Task3.md). Учебные ориентиры — соседние `main.scala` и `01_UserCli.scala`;
эти примеры не входят в сборку проекта.

Код использует обычные функции, `val`/`var`, `if`, `match`, циклы и простые коллекции.
ADT описывают команды и причины ошибок, `Option` — отсутствие значения,
`Either` — успех или ошибку операции. `map` и `flatMap` оставлены для понятных
преобразований. JSON-поля читаются и записываются явно.

## Запуск и проверки

Команды выполняются из каталога `ЛР1`. Нужны Scala CLI и JDK 17 или новее.
На текущем компьютере в `PATH` находится Java 8; установленный JDK можно указать явно:

```powershell
scala-cli compile . --server=false --java-home 'C:\Users\PC\.jdks\ms-21.0.10'
scala-cli run . --server=false --java-home 'C:\Users\PC\.jdks\ms-21.0.10' --main-class backup.backupApp
scala-cli run . --server=false --java-home 'C:\Users\PC\.jdks\ms-21.0.10' --main-class backup.backupChecks
```

Последняя команда запускает интеграционные проверки из `tests/BackupChecks.scala`.
Они создают отдельный временный каталог. Проверяются команды, настройки, изменения,
версии, шифрование, восстановление и сохранность прежних файлов при ошибках.
Сборка и все 24 группы проверок прошли. Проверка форматов включает отказ от ЛР0,
отсутствие дублирующей истории и восстановление файлов текущего формата 2.

`run.cmd` запускает приложение из каталога проекта с кодировкой UTF-8.
В `build.sbt` также описана сборка через sbt. Зависимость uJson нужна для JSON.

## Работа с программой

Можно вводить номер пункта меню или команду:

| Команда | Действие |
|---|---|
| `create` | Создать контейнер, выбрать шифрование и источники |
| `open` | Открыть существующий контейнер |
| `info` | Показать сведения |
| `sources` | Открыть меню файлов и каталогов |
| `scan` | Показать изменения |
| `backup [комментарий]` | Сохранить изменения новой версией |
| `versions` | Показать историю |
| `restore [номер]` | Восстановить выбранную версию; в диалоге Enter выбирает последнюю |
| `verify` | Проверить сохранённое содержимое |
| `reload` | Перечитать настройки |
| `help`, `exit` | Показать меню, выйти |

Источники также настраиваются командами `sources list`, `sources add`,
`sources edit <номер>`, `sources remove <номер>`, `sources enable <номер>`,
`sources disable <номер>`. Пути вводятся отдельно и могут содержать пробелы.

При первом запуске создаётся `backup.json`. В нём задаются журнал, каталог ключей,
имя контейнера, подтверждения операций, лимит версий, алгоритм хеша и исключения.
Пути считаются от рабочего каталога. `Config.validate` проверяет настройки без
создания каталогов. Папки создаются при сохранении ключа или восстановлении.
Журнал дополняется; его родительский каталог должен существовать.
При неудачном `reload` действующие настройки сохраняются.

## Устройство и ограничения

В ZIP находятся `meta/filerecords.json` с описанием источников и версий и
`blobs/<хеш>` с содержимым файлов. Одинаковое содержимое хранится один раз.
Поддерживается только текущий формат 2; контейнеры формата ЛР0 не открываются.
Путь `s0/a.txt` относится к первому источнику. Недоступный источник не считается
удалённым; неудачная новая копия сохраняет прежние данные в снимке.
Лимит применяется отдельно к истории содержимого каждого файла, поэтому старые
снимки могут стать частичными.

Для шифрования используется библиотечный AES-GCM. Ключ сохраняется отдельно или
показывается пользователю без записи. Метаданные, имена путей и хеши остаются
открытыми. Файлы читаются в память целиком: это упрощает код, но очень большие
файлы могут исчерпать память. Существующий контейнер при создании
не затирается; обновление и восстановление сначала пишут временный файл.
Атомарность замены при отключении питания не гарантируется.

Порядок чтения кода, примеры работы снимков и назначение библиотечных вызовов
описаны в [РАЗБОР.md](РАЗБОР.md). ZIP, uJson, AES-GCM и часть файловых API
потребуют отдельного изучения: в приложенных материалах занятий они не разобраны.
